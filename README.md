Breast Cancer Detection Using Machine Learning 
◦ Developed a web-based application for early breast cancer detection using a Logistic Regression Machine Learning
model. Users can input their medical data to receive real-time predictions about their risk of malignancy or benignancy.
◦ The platform includes an integrated chatbot for guidance, ensuring accessibility, efficiency, and support. By improving
access to early diagnosis tools, the system empowers users to make informed healthcare decisions.
